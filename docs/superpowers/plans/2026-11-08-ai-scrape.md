# Shared AI Price Provider Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refresh each user's AI Scrape assets with one web-enabled LLM request, using administrator-managed OpenAI or Claude API keys shared across SIP-D users.

**Architecture:** Keep Flask, SQLite, server-rendered forms, and the existing refresh/snapshot workflow. Add a shared encrypted configuration, two provider adapters behind one validated quote contract, and a shared cache/lease coordinator. Routes retain ownership enforcement; the LLM never receives database access or private portfolio data.

**Tech Stack:** Python 3.12+, Flask, SQLite, requests, Decimal, pytest, vanilla JavaScript; add `cryptography` for Fernet encryption. Use standard-library multiprocessing for a cancellable provider call; no external job queue or AI framework.

**Spec:** [Shared AI price provider](../specs/2026-11-08-ai-scrape-design.md). The user accepted proceeding to planning on 2026-11-08; implementation is not part of this planning task.

## Global Constraints

- API keys only; no account/subscription login. OpenAI and Claude require separate keys.
- One shared configuration, one active service per request, administrator-only credential management.
- Original setup user administers the shared connection; existing-user migration chooses earliest `created_at`, then ID, exactly once.
- One batch contains all uncached instruments for the requesting user; no automatic second paid request or provider fallback.
- Cache quotes for the existing 15-minute policy (`SIPD_QUOTE_CACHE_TTL_SECONDS=900`). Preserve non-AI cache behavior.
- Reject quotes older than seven calendar days, future timestamps, nonpositive/non-finite prices, mismatched identities/units/currencies, missing sources, and missing web-search evidence.
- AI deadline is **60 seconds total**, including connection, response read, extraction, and validation. No database transaction spans network work.
- Store source URL, price kind, and actual quote time; cache fetch time is separate.
- Preserve previous prices on failure and keep writes and snapshots scoped to the requesting user.
- No legacy Go implementation, account-management UI, OAuth, background queue, portfolio-data prompts, or model-controlled tools beyond web search.
- Prefix local shell commands with `rtk`; use `rtk proxy` for commands without a dedicated RTK wrapper. CI runner commands retain their existing form because RTK is not installed there.

## Review Focus

- Settings change during a slow response: discard the old revision's result before caching or updating assets (Tasks 5–6).
- An expired lease owner finishes after a new owner starts: token-checked release/finalization must not unlock or overwrite the newer work (Tasks 5–6).
- A weekend cached quote crosses the seven-day limit while its fetch cache is fresh: reject it using quote time, independently of cache TTL (Tasks 3, 5).
- An asset is archived or its provider/symbol changes during refresh: recheck current ownership and instrument before saving (Task 6).
- Malicious model/provider strings, source URLs, or error bodies: never execute/render HTML, leak credentials, or accept arbitrary URL schemes (Tasks 3–4, 7).

## Repository map and implementation decisions

Existing integration points: `sipd/routes.py` contains `setup`, `settings`, `asset_save`, `ticker_check`, `refresh`, `price_lookup`, and the nested `save_asset_quote`; `sipd/templates/page.html` contains all corresponding forms. There is no separate asset-form template and no administrator field today. `price_refreshes` is currently written after provider calls, so its uniqueness constraint alone does not prevent duplicate paid calls.

Use provider value `ai_scrape` and label **AI Scrape**. Administrator chooses a model ID per service; do not auto-select a potentially expensive model. Require a nonempty model for the active service. A Test connection button performs a small web-enabled quote request and explicitly says it may incur usage charges.

Use one global configuration row and provider runtime rows keyed by service. Cache identity uses a configuration revision; an existing provider-wide Retry-After deadline survives a revision change, because changing a model does not remove an account's rate limit. This is a clarification of the spec's cache/backoff invalidation: invalidate instrument failures, retain an outstanding account-wide server cooldown.
