# Wallet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the old RDN-backed cash workflow as the user-facing Wallet feature.

**Architecture:** Keep Wallet code in `sipd/routes.py`, next to existing transaction handlers. Private helpers provision the fixed-IDR Wallet asset, replay its ledger, and rebuild derived prices. Jinja adds the Wallet navigation and page; paired writes/deletes use the existing `transaction(db)` context manager.

**Tech Stack:** Python 3.12, Flask, Jinja, SQLite, `Decimal`, pytest.

**Spec:** `docs/superpowers/specs/2026-08-29-wallet-design.md`

## Global Constraints

- Use `Decimal` for Wallet values and preserve `RDN` plus `rdn:auto:<origin-id>` internally.
- Scope all SQL by `user_id`; write paired entries atomically.
- Add no migration, dependency, ORM, or payment provider.
